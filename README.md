# AI Engineer Learning Resource

A concise, high-yield, one-course-per-topic roadmap for building modern agentic AI systems.

## Curated Learning Roadmap (One Course per Topic)

### 1) AI Agents: LangChain & LangGraph
- **Course:** [AI Agents in LangGraph (DeepLearning.AI)](https://www.deeplearning.ai/short-courses/ai-agents-in-langgraph/)
- **Covers:** Graph-based agent design, cyclical state, tool-calling, multi-agent workflows, and human-in-the-loop patterns.
- **Why this one:** Built by core LangChain/LangGraph maintainers, with production-ready agent patterns (not just demo prompt loops).

### 2) Databricks: Generative AI Engineering
- **Course path:** [Databricks Academy](https://www.databricks.com/learn/training/home) (Generative AI Engineer learning content)
- **Optional cert track:** [Databricks Certified Generative AI Engineer Associate](https://www.databricks.com/learn/certification/generative-ai-engineer-associate)
- **Covers:** Mosaic AI, Vector Search, MLflow, Unity Catalog governance, and LLM deployment on Databricks.
- **Why this one:** Teaches the enterprise-grade data/AI platform patterns used to securely operationalize AI applications.

### 3) Cloud (Azure): Security + Identity + Networking Focus
- **Modules:** [AZ-104 on Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/azure-administrator/) and [AZ-305 on Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/azure-solutions-architect/)
- **Covers:** Entra ID, VNets, Private Endpoints, Key Vault, and RBAC.
- **Why this one:** Focused official modules help you learn exactly what is needed to deploy and secure AI/data workloads without over-investing in broad cloud survey content.

### 4) Kubernetes & Containerisation
- **Course options:** [Kubernetes for Beginners (KodeKloud)](https://kodekloud.com/courses/kubernetes-for-the-absolute-beginners-hands-on/) or [CKAD course path (KodeKloud)](https://kodekloud.com/learning-path/certified-kubernetes-application-developer/)
- **Covers:** Docker basics, Pods, Deployments, Services, ConfigMaps, and operating containerized apps.
- **Why this one:** Hands-on labs in each lesson accelerate practical deployment skills for microservices and model-serving runtimes.

## Suggested Execution Order
1. Start with **AI Agents** to quickly build tangible systems.
2. Move to **Databricks** to scale data + AI components correctly.
3. Use **Azure** and **Kubernetes** in parallel as practical references for deployment, security, and containerization.
